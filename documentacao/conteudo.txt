Objetivo e resultado esperado
Uma jornada intensiva, prática e orientada a evidências de engenharia.
MISSÃO
Construir uma carteira digital simulada com arquitetura 
multimódulo, operação offline, segurança, testes e 
pipeline de entrega.
O foco não é apenas “funcionar”: a solução precisa ser 
explicável, sustentável e resiliente.
COMPETÊNCIAS
Clean Architecture
MVI / fluxo unidirecional
Room + WorkManager
Keystore + biometria
EVIDÊNCIAS
Código e pull requests
Testes e cobertura de 50%
Pipeline e APK (Utilizar do firebase)
Demonstração técnica

Avaliação e Definition of Done
A entrega é medida pelo produto e pela forma como a solução foi construída.
Arquitetura 20%
Código 15%
Offline + sync 15%
Segurança 15%
Testes 15%
CI/CD 10%
Docs + defesa 10%
DEFINITION OF DONE
Critérios de aceite atendidos
Estados de loading, sucesso, vazio e erro
Offline tratado quando aplicável
Testes e análise estática aprovados
Sem exposição de dados sensíveis
Acessibilidade básica
Code review concluído
Documentação e demonstração atualizadas
RESULTADO FINAL: código-fonte + APK + README + diagramas + ADRs + cobertura + pipeline + apresentação
